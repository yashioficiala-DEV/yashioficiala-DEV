# Ola! Eu sou a YASHI

Crio ferramentas para **Roblox Studio** em português.

## Projeto principal: YashScript

O **YashScript** é uma linguagem de programação em português para Roblox Studio.
Você escreve o código de forma natural (eventos, objetos e comandos simples) dentro
do próprio script, e um plugin gera **Luau puro** no *Source* — pronto pra rodar.

Veja o projeto completo:

**[YashScript-Roblox-Studio](https://github.com/yashioficiala-DEV/YashScript-Roblox-Studio)**

- [Baixe o instalador](https://github.com/yashioficiala-DEV/YashScript-Roblox-Studio/releases) (2 cliques, sem instalar o plugin na mão)
- Compatível com `Script`, `LocalScript` e `ModuleScript`
- Gera Luau puro, sem depender de módulos extras

## Como instalar

1. Feche o Roblox Studio.
2. Baixe o `instalar.cmd` da página de **Releases**.
3. Ele baixa a versão mais recente e instala sozinho.
4. Abra o Roblox Studio e procure o YashScript na Toolbox.
